# 灵感骰子 · Idea Dice

给 DeepSeek Harness 装一盒创作卡、一只选择转盘和一套多面骰。纠结做什么时，抽一张有场景、有玩法、有约束的挑战卡，再让 Harness 帮你实现。

全部逻辑在本地运行，不需要 API Key、不联网、不保存聊天记录。结果通过原生工具卡以文字和 emoji 展示；首版没有独立窗口或转盘动画。

## 三种玩法

| 工具 | 用途 | 示例 |
| --- | --- | --- |
| `idea_draw` | 抽取代码、设计、写作、游戏灵感卡 | 「给我抽 3 个周末小游戏点子」 |
| `idea_choose` | 在明确候选项中随机选择，支持权重 | 「在画画、写代码、读书中转一次轮盘」 |
| `idea_roll` | 掷多面骰，逐颗显示结果与总和 | 「掷 4d6+2」 |

灵感卡由人工编写的主题、玩法、约束和第一步组合而成。4 个类别各有 288 种组合，共 1152 种；一次最多抽 5 张，同一次调用不会出现完全相同的组合。不同卡片可能共享主题。

例如抽到：

> 🎲 代码实验：像素日记
>
> 场景：用一格颜色和一句话记录一天。
>
> 玩法：让数据可以导出并重新导入。
>
> 限制：所有数据只保存在本地。
>
> 第一步：先写出输入、输出和一条边界情况，再做一个可运行的最小版本。

这是组合结果示例，实际随机抽取可能不同。

## 安装

已验证 **DeepSeek Harness 0.2.2-rc.2**。桌面版首次打开后会初始化 `desktop` profile。完全退出桌面版后运行：

```sh
dsh plugin --profile desktop add "https://github.com/qinghuidaqzp/dsh-idea-dice/releases/download/v0.1.0/dsh-idea-dice-0.1.0.tgz"
```

使用 `dsh web` 的用户将 `desktop` 改成 `web`。也可以从 [GitHub Release](https://github.com/qinghuidaqzp/dsh-idea-dice/releases/tag/v0.1.0) 下载 `.tgz`，将网址替换为安装包绝对路径。重启后工具即可使用，无需配置。

本版本通过 GitHub Release 提供预构建安装包，安装不需要 npm 账号。其他 Harness 版本尚未验证。

## 对话示例

- 「用 idea_draw 抽 3 张 game 类别灵感卡，选一个最适合一小时完成的点子。」
- 「给我一个不超过 500 字的写作挑战，seed 用 雨天书店。」
- 「用 idea_choose 从做小游戏、画图标、写故事里抽一个，权重分别为 3、2、1。」
- 「用 idea_roll 掷 2d20，seed 是 团队周五。」

选择工具只返回抽中的候选项，不会自动执行选项中的行为。转盘反映的是随机概率，而不是对选项优劣的判断。

## 工具参数

### 灵感卡 `idea_draw`

```json
{"category":"game","count":3,"seed":"周末实验"}
```

- `category`：`code`、`design`、`writing`、`game`，默认 `code`。
- `count`：1–5，默认 1。
- `seed`：可选，1–80 个字符。相同版本、参数与种子可复现结果；省略时使用系统随机。

返回 `ideas` 数组，每张卡包含 `title`、`brief`、`mechanic`、`constraint`、`firstStep`，同时返回适合直接阅读的 `text`。

### 选择转盘 `idea_choose`

```json
{"options":["做小游戏","画图标","写故事"],"weights":[3,2,1],"seed":"周五"}
```

- `options`：2–50 个不重复的选项，每项最多 120 个字符。
- `weights`：可选，与选项数量相同，每项为 1–100000 的正整数；省略时等概率。
- `seed`：可选复现种子。

返回选中标签、从 1 开始的 `index`、选中权重、总权重及概率。上面的三个概率分别为 50%、约 33.33%、约 16.67%。

### 多面骰 `idea_roll`

```json
{"expression":"4d6+2","seed":"桌游之夜"}
```

只接受 `NdM`、`dM`、`NdM+K`、`NdM-K`，例如 `d20`、`2d6+3`。最多 100 颗骰子，每颗 2–1000 面，加减值绝对值不超过 1000。不会执行任意代码或复杂表达式。

返回每颗骰子的 `rolls`、骰子小计 `subtotal`、修正值 `modifier`、总和 `total` 和理论范围。

## 随机性与数据

未设置 `seed` 时使用 Node.js `crypto.randomInt`；设置种子后，使用带拒绝采样的版本化 SHA-256 序列生成可复现整数。种子功能用于分享同一挑战，不提供公开抽奖的审计或防篡改保证。

插件不读取文件、环境凭据或其他会话，也不创建后台任务。与其他工具一样，调用参数和结果可能由 Harness 自身记录在当前对话中。

```sh
npm ci
```
